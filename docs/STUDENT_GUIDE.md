# CompanAI — student guide

CompanAI helps you go from an app idea to a live app using AI tools. This page gets you set up in about 10 minutes.

## 1. Create your account

Open the link your instructor shared and click **Get started**. Sign up with your email or Google.

## 2. Add your free Gemini API key (one time, ~2 minutes)

CompanAI's AI features run on **your own** free Google Gemini key.

1. Go to **[aistudio.google.com/apikey](https://aistudio.google.com/apikey)** and sign in with a Google account.
2. Click **Create API key** (accept the terms if asked) and copy the key — it starts with `AIza`.
3. In CompanAI, click **Add API key** (or **Settings**), paste it, and click **Test key**. You should see **Key works**. Click **Save**.

Your key is saved only in this browser and sent only to Google. If you switch computers or browsers, add it again there.

> **Keep your key private.** Don't post it in chat, screenshots or GitHub. If it leaks, delete it in AI Studio and create a new one.

## 3. Turn your idea into a project

1. Open the **Idea Workshop**. Describe your app — a rough idea is fine.
2. Click **Generate 3 project ideas** and pick the version you like.
3. Choose colours, layout and any extra features, then click **Generate my prompts**.
4. Click **Save project & start building**.

## 4. Build it, stage by stage

Your project page has your prompts and a build guide with four stages:

1. **Build the UI in Lovable** — paste the Lovable prompt into [lovable.dev](https://lovable.dev).
2. **Connect GitHub** — sync the project to GitHub and run it on your computer.
3. **Add the backend with Cursor** — open the project in [Cursor](https://cursor.com) and work through the Cursor prompt, one step at a time.
4. **Deploy and share** — publish it and share the link.

Tick each stage off as you finish it. Stuck? Click **Ask the mentor** (bottom-right) — it knows which project and stage you're on. Paste the exact error message when you ask about an error.

## Troubleshooting

| Message | What to do |
|---|---|
| *Add your Gemini API key in Settings* | You haven't saved a key in this browser yet — see step 2. |
| *Your Gemini API key was rejected* | The key is mistyped or was deleted. Copy it again from AI Studio. |
| *You've hit your usage limit* | Free keys allow a limited number of requests per minute and per day. Wait a minute and click **Try again**. |
| *The Gemini model isn't available for your key* | Open **Settings → Advanced options**, clear the model field, and save. If it still fails, ask your instructor which model to use. |
| *Couldn't reach Gemini / the server* | Check your internet connection. Some school or office networks block AI services. |
| Google sign-in window closes or is blocked | Allow pop-ups for the site, or sign up with email instead. |

Your workshop progress is saved automatically, so refreshing the page or closing the tab won't lose it.
